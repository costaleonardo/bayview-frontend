# Bayview Blog Demo

This is a Next.js application built with Faust.js to create a headless WordPress blog section for Bayview, demonstrating UI/UX and front-end development skills for a UI/UX Front-End Web Developer role.

## Project Overview

The project showcases a responsive blog section using WordPress as the CMS and a Next.js frontend with Faust.js for headless integration. It aligns with the job requirements, leveraging 4+ years of experience in UI/UX, WordPress, and React.

### Key Features
- **Responsive Design**: Built with HTML5, CSS3, JavaScript, and React (Next.js/Faust.js) for cross-browser compatibility.
- **WordPress Backend**: Configured with WPGraphQL for efficient content management.
- **Frontend**: Utilizes Tailwind CSS and Next.js for a user-friendly interface.
- **Version Control**: Managed with Git for streamlined development.

## Purpose
This demo was built to showcase my ability to translate requirements into a functional, responsive web solution, bridging graphical design and technical implementation. Due to time constraints, the project focuses on core functionality, with opportunities to enhance SEO and architecture for production use.
